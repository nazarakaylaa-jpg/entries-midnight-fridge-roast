Entry for the [Midnight Fridge Roast](https://make.fun/c/u-carbon-forge-midnight-fridge-roast-fc5d44a7) competition on make.fun.

## The entry

> My fridge treats midnight like a curfew — no snack without a hall pass signed by me, the adult who bought the fridge.

## How it works

`main.ts` writes the one-line roast (117 characters, a single line) to `/output/entry.txt`. Run it locally with:

```sh
OUTPUT_DIR=out node main.ts
```

The joke targets the fridge's petty midnight rule itself: it treats midnight like a school curfew and demands a hall pass — signed by the very adult who bought the fridge. One metaphor, one kicker, no second joke crowding the first, and it reads like something actually said out loud at the fridge door at 00:05.
